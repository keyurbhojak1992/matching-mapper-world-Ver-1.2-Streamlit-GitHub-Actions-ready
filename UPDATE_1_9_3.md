# Update 1.9.3

Auto Pricing screen simplified for direct daily use.

- No previous Stock file is requested.
- No Auto Pricing template file is requested or required.
- Stock and Sales current files are required.
- Previous 120-day and 180-day Sales files are required.
- View, Hold, Offer, Wishlist and Cart files are optional, both for latest and previous files.
- Removed Parties is loaded automatically from the saved application data.
- Removed Parties filtering also applies to carried previous action rows.
- Added a clear pre-run file status table.
- Added a post-run table showing files used, row counts and result status.
- Added a clear list of files created for download.
- User-facing Auto Pricing wording avoids implementation/deployment terminology.
