# Repository default inputs

When a user does not upload the corresponding file, the application reads these exact paths:

- `data/PARTY_PROFILE_PERM.parquet`
- `data/PARTY_PROFILE_TEMP.parquet`
- Suggested/BID filter defaults: built into `defaults/suggested_rules.py`
- Suggested/BID no-need defaults: built into `defaults/suggested_rules.py`
- `data/Bid_Summary.xlsx` — default source for the **Pricing Last 5 BID Suggested** workspace. The workspace recalculates the latest N numeric Bid groups and rebuilds its temporary pricing profile on every run.

The binary business-data files are not generated by the application. Add the current verified copies to this folder in the private repository.

- `data/remove_parties.xlsx` — default Auto Pricing Removed Parties master.
